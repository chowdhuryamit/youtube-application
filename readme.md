# YouTube Application Backend

## Overview
This repository contains the backend logic for a YouTube-like application as assigned by Hitesh Choudhury. The application includes controllers for managing users, videos, playlists, and dashboards.

## Features
### User Controller
- User registration and authentication
- Profile management
- Subscription handling

### Video Controller
- Upload, update, and delete videos
- Fetch video details
- Like, dislike, and comment on videos

### Playlist Controller
- Create and manage playlists
- Add or remove videos from playlists

### Dashboard Controller
- View analytics on videos and user engagement

## Usage
- API endpoints can be tested using Postman or an API client.
- Users can register, log in, upload videos, create playlists, and manage their accounts.
